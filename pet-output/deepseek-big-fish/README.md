## 生成方式与最终提示词

使用内置 ImageGen，共12项视觉生成：1张主形象、8条独立状态动画、1条四方向锚点、2条连续视线动画。向左移动由已审核的向右移动逐帧镜像得到，保留时间顺序。未使用CLI或外部API。

主形象提示词：根据参考设定图生成一个完整全身的二头身Q版少女，蓝紫至浅蓝渐变长卷发、蓝色大眼睛、白色褶边女仆头箍、弧形呆毛、鲸鳍耳饰与蝴蝶结、深蓝白色女仆裙、白围裙上的蓝色鲸鱼图案、白袜深蓝鞋；背后粗壮圆润的深蓝鲸尾带浅蓝腹侧，紧凑收拢并与身体保持连接。精致日系动漫描线、柔和赛璐璐阴影、保持参考图身份，小尺寸清楚可读。完整居中，纯绿色背景用于确定性透明提取，无文字、网格、地面投影、漂浮特效或额外道具。

状态提示词：每次附上参考设定图、主形象和对应布局指南，生成指定帧数的同角色横排全身动作，保持身份、配色、服装、比例与鲸尾连接。待机6帧轻呼吸眨眼；移动8帧交替步态；挥手4帧开始举手摆动回落；跳跃5帧下蹲起跳最高点下降落地；受挫8帧沮丧低头再缓和；等待6帧双手胸前期待与轻歪头；处理中6帧双脚固定、专注思考与胸前手部动作；检查结果6帧托腮审视、扫视和满意微笑。不画布局线、标记、文字、阴影或脱离特效。

视线提示词：先生成上、屏幕右、下、屏幕左四个完整全身锚点，再附主形象、标准状态、布局指南和审核锚点，分两次绘制同一连续16姿态家族。依序000、022.5、045、067.5、090、112.5、135、157.5，然后180、202.5、225、247.5、270、292.5、315、337.5。头眼引导注意力、眼睑眉毛参与、头饰头发自然跟随；身体鞋底裙摆和鲸尾锚点稳定，鲸尾不换侧。上下明确仰头或低头且眼睛看对应方向，左右鼻尖和瞳孔朝对应屏幕方向。保持尺度与基线，禁止整体旋转扭曲、替换眼睛或添加标记。
