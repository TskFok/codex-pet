# DeepSeek娘视线机制

鞋底、围裙正中鲸纹、臀后鲸尾的根部和躯干保持同一基线与横向位置。下裙和宽大的双叶鲸尾始终连在原处。头部、颈部和眼神围绕这个支点活动，身体只有极小的伴随动作。压住肩膀和躯干旋转，保留正面角色轮廓和画面右后方的鲸尾，尾尖可随动 1–2 像素。不要换尾所在一侧。

眼睛先瞄准目标，原作的深蓝瞳孔、分层亮蓝虹膜与高光在眼眶内成组转动。眼皮、睫毛和眉毛随目光开合，脸和颈部紧接着偏转。保持脸宽、眼距、发型、头箍、呆毛、两侧鲸鳍耳翼和双蝴蝶结的实体结构。头箍与呆毛跟头一起移动，发梢与软鳍耳有轻微跟随。无手持道具。每步约 22.5° 的目标方位，对应头部最多约 8° 的平滑俯仰或转向变化，控制整体轮廓和基线连续。

| 000 正上 | 脸总体正对观众，抬颏露出少量下颌，鼻嘴在头部轮廓内略上移，清澈蓝眼朝顶边看。上眼睑打开，眼睛下缘可见少量眼白。两侧耳翼的露出量大致相等。 |

| 180 正下 | 脸总体正向，收下巴靠近领结。眼睛保持睁开，露出深蓝瞳孔，瞳孔贴向下睑，上缘有少量可见眼白。顶侧发面与头箍露出增多，保留双眼和识别度。 |
| 270 屏幕左 | 用相近幅度向屏幕左边转头，鼻尖与瞳孔明确越过头中心朝左。画面右侧近颊与耳鳍显露，左侧远眼和耳翼有小幅遮挡。尾巴继续在画面右后方，脚底不侧滑。 |

每个斜向保留水平和垂直两轴。斜向靠近垂直方向时，水平转头可以较小。两个跨行接缝 157.5°→180° 和 337.5°→000° 只保留一步幅度，避免角色缩放、轴反转、头发或尾巴横跳。保持所有方向下的两侧瞳孔和目光可读。
