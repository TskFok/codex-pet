# deepseek大肥鱼的视线动作

角色为独立头部的二头身动漫人形。身体、鞋底、白围裙中心和鲸尾根部固定；鲸尾始终留在身体同一侧后方，不随视线翻转，也不出现多条尾巴。裙摆与双手保持安静。头部和脸使用正常刚性转向，长发、头箍、鲸鳍耳饰和呆毛随头部小幅连续转动，不拉伸脸部比例。

大眼睛先引导方向：虹膜、眼白、眼睑和高光一起随头部视角重绘，眼睑和眉毛响应；禁止在原眼睛上粘贴新眼或让瞳孔脱离眼眶。表情保持同一个安静可爱的角色。

四个锚点均以观看者的屏幕方向为准：
- 000 向上：头保持正面、抬下巴，脸朝上，瞳孔显著靠眼眶上部，上眼睑打开；仍可辨认蓝色眼睛，不能闭眼冒充抬头。
- 090 向屏幕右：头部向右转约55度，鼻尖和可见瞳孔明显位于头中心右侧；左侧脸颊更显露，远侧眼部分遮挡，身体只轻微跟随。
- 180 向下：正面低头、收下巴，蓝色瞳孔显著向下，额头和头顶更可见，下巴靠近胸口；不能只是闭眼。
- 270 向屏幕左：与090相反，头部左转约55度，鼻尖和瞳孔明显在头中心左侧；右侧脸颊更显露、远侧眼遮挡，服装和鲸尾不能翻转。

每个22.5度增量均匀插值：头部偏航约55*sin(angle)度、俯仰约25*cos(angle)度；这是绘制意图，不应用像素级仿射变形。正上和正下无水平偏航，正左和正右无明显仰俯。对角线同时具备对应水平与垂直线索。保持头大小、身体高度、体积和鞋底基线一致。相邻帧的眼睑、头发与耳饰小幅连续跟随，157.5到180及337.5到000不得突然回正、变大或尾巴跳边。禁止整个精灵旋转、倾斜或扭曲来假装看向某处。
